# סולמות ונחשים באסמבלי

פרויקט גמר של כיתה י' באסמבלי: משחק סולמות ונחשים לשני שחקנים.

## הרצה

הדרך הפשוטה היא להשתמש ב-DOSBox:

1. פותחים את DOSBox.
2. מחברים את תיקיית הפרויקט ככונן (מחליפים את הנתיב בנתיב לתיקייה במחשב):

```dos
mount c C:\path\to\asm_proj
c:
base
```

חשוב להשאיר את `BASE.EXE` ואת כל קובצי ה-BMP באותה תיקייה.

## בנייה מחדש

אם TASM ו-TLINK מותקנים וזמינים ב-DOSBox:

```dos
tasm /zi base.asm
tlink /v base.obj
base
```

במהלך המשחק משתמשים במקש רווח, ו-`Esc` יוצא מהמשחק.
